# Foxhole Fire Calculator

A community-made fire mechanics calculator for Foxhole.

## Features

- Fire Stack calculator
- Building fire resistance database
- Weapon comparison
- Raid simulation
- Weather impact simulation
- Fire extinction calculator

## Project Status

🚧 Early development

## Technology

- HTML5
- CSS3
- JavaScript
- JSON
- GitHub Pages

## Data Policy

This project targets the latest Foxhole game version only.

Game mechanics values will be documented and updated when changes occur.
